# مدار — إدارة المهام والتذكيرات

تطبيق عربي باتجاه RTL يناسب الجوال وسطح المكتب، دون حزم أو خطوة بناء أو خدمات خارجية.

## التشغيل

من المستودع شغّل:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

الصفحة هي `/Index.html` بحرف I كبير. عنوان الجذر يعرض قائمة الملفات.

## الاستخدام

- إضافة المهام وتعديلها وحذفها مع تأكيد الحذف.
- تحديد الأولوية والتصنيف والموعد والملاحظات.
- إكمال المهام وإعادة فتحها، والبحث والتصفية والترتيب.
- إحصاءات الإنجاز وقائمة المواعيد القادمة.
- تذكيرات داخل الصفحة وإشعارات المتصفح عند دعمها ومنح الإذن.

تظهر مهمة تجريبية واحدة عند أول استخدام ويمكن حذفها. تُحفظ البيانات محليًا في `localStorage` في المتصفح نفسه، ولا تتزامن بين الأجهزة. حذف بيانات الموقع يمحو المهام. تتطلب التذكيرات بقاء التطبيق مفتوحًا، وقد تؤخرها قيود المتصفح في الخلفية. الإشعارات ليست خدمة تنبيه مضمونة عند إغلاق الصفحة. يتطلب إذن الإشعارات سياقًا آمنًا مثل HTTPS أو localhost.

## التحقق

اختُبرت الإضافة والتعديل والإكمال والحذف وإلغاؤه والبحث والتصفية واستمرار الحفظ بعد إعادة التحميل باستخدام Chromium. تم فحص عدم وجود تجاوز أفقي عند عروض 360 و390 و768 و1440 بكسل. لا يحتاج التشغيل خطوطًا أو أيقونات خارجية.
